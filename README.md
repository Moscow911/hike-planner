#  Hike Planner — Веб-приложение для планирования походов и маршрутов

Веб-приложение, позволяющее пользователям планировать туристические походы, строить и сохранять маршруты на интерактивной карте, отслеживать прогноз погоды и общаться в чате поездки.

---

##  Основной функционал

* **Авторизация и профили:** Регистрация и вход пользователей с возможностью создания и редактирования личных маршрутов.
* **Интерактивная карта:** Построение и визуализация треков поездок с использованием **Leaflet**.
* **Погода в реальном времени:** Интеграция с **Open-Meteo API** для получения прогноза погоды вдоль маршрута.
* **Управление поездками:** Создание, редактирование и удаление сохраненных маршрутов (с автоматическим закрытием связанного чата при удалении поездки).
* **Чат поездки:** Встроенное обсуждение детализации маршрута участниками.

---

##  Технологический стек

* **Backend:** Node.js, Express.js
* **База данных:** SQLite / PostgreSQL, ORM Sequelize
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Leaflet.js
* **API:** Open-Meteo API

---

##  Инструкция по локальному запуску

Для запуска приложения на локальном компьютере выполните следующие шаги:

### 1. Клонирование репозитория
git clone https://github.com/Moscow911/hike-planner.git
cd hike-planner

### 2. Установка зависимостей
npm install

### 3. Запуск сервера
node index.js

После запуска откройте браузер и перейдите по адресу: http://localhost:5000
